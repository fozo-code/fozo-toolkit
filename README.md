# FOZO Toolkit

أداة طرفية عربية خفيفة لـ **Termux على Android**، مبنية بـ Python.

## المميزات

- معلومات أساسية عن النظام ومساحة التخزين.
- توليد كلمات مرور باستخدام مولد عشوائي آمن.
- أدوات Base64 و SHA-256.
- إنشاء QR Code (اختياري).
- عرض حالة مستودع Git.
- استعلام DNS.
- معرفة عنوان IP العام عبر خدمة خارجية.

## التثبيت

افتح Termux ونفّذ:

```bash
pkg update
pkg install git
git clone https://github.com/USERNAME/fozo-toolkit.git
cd fozo-toolkit
bash install.sh
```

استبدل `USERNAME` باسم حساب GitHub الذي رفعت إليه المشروع.

بعد التثبيت شغّل الأداة من أي مجلد:

```bash
fozo
```

### ملاحظات

- المثبّت مخصص لتطبيق Termux على Android، وليس Linux العام.
- إنشاء QR يحتاج اتصال إنترنت أول مرة لتثبيت المكتبة من داخل الأداة؛ ثبّتها من القائمة عند الحاجة.
- ميزة IP العام تتصل بـ `api.ipify.org`.
- لا ترفع كلمات المرور أو الأسرار إلى مستودع عام.
